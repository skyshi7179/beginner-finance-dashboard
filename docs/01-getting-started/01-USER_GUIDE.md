## 1. 平台能做什么

这是一个在自己电脑运行的金融数据研究工具。你可以先保存历史行情，再利用同一份缓存画图、运行双均线研究回测、生成报告。通常不需要搭建云服务器，也不接真实券商账户。

### 1.1 已有功能

| 功能 | 你可以完成的操作 | 当前状态 |
| --- | --- | --- |
| 首页工作台 | 进入各模块，返回首页 | 已实现 |
| 股票/ETF数据获取 | 按代码或中文名称搜索、明确选择证券、选择日期和复权方式、获取日线、保存本地、导出CSV | 已实现；真实获取依赖数据源和网络 |
| 本地行情缓存 | 重复请求优先读缓存，补充未覆盖区间，按证券类别/代码/频率/请求复权隔离保存 | 已实现；数据管理页支持查看、转存、移出与恢复 |
| 金融数据可视化 | K线、成交量、MA5/MA20、日收益率、累计收益率、回撤与统计指标 | 已实现；只读本地缓存 |
| 自定义策略回测 | 双均线、通道突破、简单RSI、日线研究网格、条件编辑器及可选AI规则草案；次日开盘研究执行 | 已实现；不代表精确实盘 |
| 研究报告 | 四类报告、结构化事实核验、规则/模型模式、Markdown及指标CSV导出 | 已实现；真实外部模型需由用户配置并主动测试 |
| 数据管理 | 永久/本次临时缓存清单、批量回收与恢复、模型/API设置、结束本次使用清理 | 已实现 |

平台不提供实盘下单、收益承诺或未来走势预测。已实现页面不等于上游接口始终可用，也不代表覆盖全部证券。

### 1.2 首页导航

首页上方三个核心入口：

- **进入数据获取**：先取得股票或ETF行情。
- **进入可视化分析**：分析已经缓存的行情。
- **进入策略回测**：使用缓存选择策略模板或编辑自己的条件。

下方“进阶分析”：

- **进入研究报告**。
- **进入数据管理**：查看永久和本次临时行情，批量回收/恢复，或配置模型与API。

每个子页面均有返回首页路径。正常页面切换和重绘会尽量保留已选证券、日期、复权方式及相关偏好。各页面可能保留自己的日期选择，切页后应确认顶部条件；关闭会话、刷新浏览器或重启应用后，不保证所有控件和结果恢复。本地缓存文件不会因此消失。

## 2. 安装与启动

### 2.1 本机已有环境时

在VS Code中打开项目整个文件夹，激活项目虚拟环境后运行：

```bash
python -m streamlit run app.py --server.headless false
```

终端出现`Local URL`后，打开该地址，通常为`http://localhost:8501`。如果端口被占用，以终端实际显示的端口为准。浏览器没有自动打开时，可以点击终端中的地址，或复制到浏览器地址栏。

**为什么不能直接运行app.py？** 本项目是网页应用，必须由Streamlit启动本地服务，再由浏览器显示。直接点击普通Python“运行文件”与启动Streamlit服务不是同一件事。

### 2.2 VS Code一键运行

1. 确认VS Code当前打开的是项目根目录，而不是单独打开`app.py`。
2. 打开左侧“运行和调试”。
3. 选择`Streamlit: 新手金融数据平台（启动并打开浏览器）`。
4. 点击绿色启动按钮，或按F5。
5. 若首次启动终端停在`Email:`，可以直接按回车跳过。

该配置使用VS Code当前选中的Python解释器。请先通过“Python: Select Interpreter”选择项目`.venv`中的解释器。进入页面不会自动获取股票/ETF数据，需主动点击获取。

### 2.3 新电脑首次安装

本项目已在macOS Apple Silicon、Python 3.11.15环境完成验证。Windows和Linux也可以本地运行，因为应用通过Streamlit在浏览器中显示；这些系统需要分别安装与自身平台匹配的Python及依赖包。新环境建议优先使用Python 3.11。

macOS或Linux：

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.headless false
```

Windows PowerShell：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.headless false
```

如果PowerShell不允许执行激活脚本，可在Windows命令提示符中运行：

```bat
.venv\Scripts\activate.bat
python -m streamlit run app.py --server.headless false
```

首次安装依赖需要网络。当前Streamlit固定为已验证的1.66.0，其他依赖没有固定所有版本，因此未来安装到不同版本时，兼容性仍需重新确认；不把本机验证等同于所有环境均已验证。

### 2.4 停止与重启

- 终端启动：回到运行服务的终端按`Control+C`。
- VS Code调试启动：点击停止按钮。
- 更新代码或模型配置后，停止旧服务再重新启动。
- 仅关闭浏览器标签通常不会停止服务；应用运行时不要关闭它所在的终端。

## 3. 第一次使用：完整操作路线

推荐按下面顺序熟悉平台：

1. 首页点击**进入数据获取**。
2. 选择A股或ETF，例如查询ETF时先选择ETF，再输入`159516`。这只是操作示例，不是推荐证券。
3. 点击**搜索**，在匹配列表确认代码、名称及市场。
4. 选择历史日期区间和复权方式，点击**获取数据**。
5. 检查状态、实际复权、来源、覆盖日期和记录数。成功后数据保存在本机。
6. 点击**前往可视化分析 →**，查看图表及风险收益指标。
7. 点击**进入策略回测 →**，确认区间和MA参数，点击**运行回测**。
8. 返回首页，进入**研究报告**，选择同一证券和区间，再点击**生成研究报告**。
9. 下载需要保留的CSV、ZIP或Markdown。

如果没有网络或真实缓存，页面会提示缺少数据，不自动下载、不生成假行情；先在可访问数据源的网络下主动获取，再离线研究。

## 4. 股票与ETF数据获取

### 4.1 搜索并选择证券

1. 在“搜索类别”选择**A股**或**ETF**。
2. 在“代码或中文名称”输入6位代码或名称，点击**搜索**。
3. 在“选择目标证券”中明确选择匹配项，确认代码、名称和市场。
4. 找不到新上市证券时，可点击**刷新A股代码表**或**刷新ETF代码表**后重试。

代码表优先读取本地文件；第一次搜索缺少代码表时可能联网建立缓存。刷新代码表更新的是“证券名单”，不是历史价格。中文搜索支持名称包含匹配，不是拼音或智能语义搜索。

ETF代码表目前合并AKShare可取得的新浪和同花顺ETF名单，不能保证任何时点都完整。搜索结果存在也不保证行情接口支持该证券。北交所复权历史目前不受当前行情接口支持。

### 4.2 设置日期与复权方式

三个核心页面分别提供开始日期、结束日期和“至今（完整日线）”。勾选至今后，根据本地provider-derived交易日历：未收盘取上一交易日，收盘后允许请求今天，但最终以实际返回日期为准；周末节假日不会简单按昨天处理。支持近1个月、近3个月、近1年快捷区间，需点击“应用快捷区间”。改变日期本身不下载行情。日历未覆盖当前日期时至今禁用，提示手工选择。开始日期不能晚于有效结束日期。

| 方式 | 通俗理解 | 使用时注意 |
| --- | --- | --- |
| 前复权qfq | 以较新的价格尺度调整较早历史价格，减少除权除息造成的价格断点 | 适合观察同一口径的历史价格变化；历史值可能随后续公司行为被修订 |
| 后复权hfq | 以较早的价格尺度调整后续价格 | 数值尺度可能与当前交易价格差别较大，不能当作实际成交报价 |
| 实际返回none | 数据源只返回原始不复权日线 | 平台保留请求方式，同时明确标记实际none，不会冒充qfq/hfq |

数据获取页面提供前/后复权请求。部分证券没有对应复权序列时会显示原始日线提示。**分析应以实际复权字段为准**，不能只看你在下拉框中请求了什么。

### 4.3 获取与刷新

获取前选择“行情保存方式”：保存到本地，或“仅本次使用（临时保存）”。后者也会写入项目的独立会话目录，供可视化、回测和报告读取；不是内存模式。失去会话活跃信号约10分钟后自动清理；应用关闭期间无法清理，下次启动兜底。不要把它理解为关闭标签瞬间必删，刷新或长时间休眠也可能导致会话失效。

- **获取数据**：先查缓存；覆盖充分时直接返回，否则请求未覆盖区间并合并保存。
- **强制刷新数据**：重新请求所选区间，用本次有效记录更新同日期旧记录。用于更新旧数据或补充旧缓存字段，仍可能受网络限制。

保存前会规范字段、按日期排序去重，并记录来源与元数据。接口报错会保留已有缓存；界面可能同时显示错误和旧数据，应检查旧更新时间。非交易日没有行情不一定是失败。

成交量或成交额的“待核验”按已有价格日线逐行统计，并区分来源冲突、字段待补充、补充源失败、沿用旧值和旧缓存口径。它不等于缺少交易日。法定休市日本来没有日线，不计入成交字段异常；详细日期和原因可在“成交数据来源与校验”中查看。

缓存覆盖是已记录的成功查询范围，**不代表已经逐日核对交易所日历或证明没有漏掉任何交易日**。复权历史可能修订，缺口补充也不等同于完整重建全部历史；需要统一更新已存历史时应考虑强制刷新相关区间，并重新核对口径。

### 4.4 全部历史与实际覆盖

快捷区间新增“全部历史（上市以来，尽数据源所能）”。点击“应用快捷区间”只设置日期，再点击“获取数据”才联网。未核验上市日期时以1990年作为查询起点，按数据源分页能力获取，不能把最早返回日冒充已确认上市日。缓存元数据标记history_completeness=UNVERIFIED。

可视化与回测的快捷项是“全部已缓存区间”，仅选择本地实际最早/最晚记录，不自动获取缺失历史。返回记录少于预期时先核对实际覆盖、上市日期、来源限制及错误，不声称已获得全部数据。

### 4.5 表格、单位与导出

| 字段 | 含义 |
| --- | --- |
| date | 日期 |
| open / high / low / close | 开盘/最高/最低/收盘价；实际复权时为调整后的价格尺度 |
| volume | 成交量；本项目标准化后的股票为股、ETF为份，具体以逐行单位为准 |
| amount | 成交额，元；为实际交易金额，不随价格复权调整 |
| requested_adjustment / adjustment | 请求复权方式 / 实际返回方式 |
| source / provider | 价格来源 / 接口标识 |
| volume_unit / amount_unit | 成交量/成交额单位 |
| volume_source / amount_source | 成交数据各自来源 |
| turnover_status | 成交数据校验状态 |
| fetched_at / turnover_fetched_at | 价格/成交数据采集时刻 |

当前价格OHLC主要来自腾讯，成交量和成交额由新浪历史行情补充并核验，不能把它们误认为全部来自单一数据源。补充失败时可能仍有有效价格，但成交数据为空、冲突或沿用旧值，界面会提示。

展开**成交数据来源与校验**可检查具体状态。点击**下载 CSV**导出当前结果。页面显示中英文说明，行情CSV保留标准英文列名及单位、来源字段，便于程序复用。

## 5. 金融数据可视化

从首页进入可视化，或从数据获取页点击对应入口。

1. 选择本地证券、缓存请求复权方式和分析日期。
2. 检查顶部实际区间、实际复权、来源和更新时间。
3. 在“图表内容”选择K线、成交量、可选成交额、日收益率、累计收益率和回撤。
4. 在“移动均线”显示/隐藏MA5、MA20。
5. 下载**指标计算结果 CSV**，或进入策略回测。

默认只读缓存。调整图表和日期不会自动请求行情；缺失时可点击“获取缺失数据并继续”，在小弹窗明确选择保存方式并确认获取，复用原服务。也可前往数据获取。部分覆盖时只分析现有记录，并显示提示。

### 5.1 图表怎么操作

- 悬停查看日期和数值。
- 用框选、时间滑块或工具栏缩放；可用图表重置控件恢复视图。
- 点击图例显示或隐藏曲线。滚轮默认用于页面，每张图旁点击“开启本图缩放”后仅该图响应滚轮；开启另一张会释放上一张。点击“关闭本图缩放”恢复页面滚动。触控板开启后普通双指滑动仍可能缩放，精细捏合未做跨浏览器保证。
- K线和成交量共用日期轴，价格图提供时间范围滑块。
- 每张图卡片悬停会高亮。单位未确认或缺失时只留下相应日期空白，其余日期继续绘制；×标记表示缺失，不是成交量0。缺失日期可展开查看。
- 成交量图固定按股/份或万股/万份展示，成交额图固定按元/万元/亿元展示；CSV保持基础股/份/元，并带单位与来源。
- 右下角悬浮外观按钮可直接选择浅色、深色或跟随系统，滚动和切页均可使用。

### 5.2 指标怎么理解

| 指标 | 含义与口径 |
| --- | --- |
| 区间价格累计收益率 | 最后有效收盘相对首个有效收盘的变化比例，可理解为以首收盘为基准持有至终点的价格表现 |
| 日收益率 | 相邻有效收盘价的简单变化率；首项为空 |
| MA5 / MA20 | 所选样本内过去5/20个有效观测的收盘均值；不满窗口为空 |
| 年化波动率 | 简单收益率的样本标准差乘以√252；观测不足时不计算 |
| 最大回撤 | 收盘归一化净值相对此前峰值的最大下降幅度；摘要用正的损失幅度表示 |
| 日涨跌幅平均值 | 有效简单日收益的算术平均，不等于累计收益除以天数 |
| 有效交易日 | 通过本模块价格及已知零成交检查的观测数，不是自然日数 |

均线从所选区间开始计算，不读取更早数据预热；改变起点会影响前段均线。日期空档不补齐；已识别跨缺失交易日的区间收益保存在observation_return，不计入daily_return的均值及波动率；本地日历未覆盖时无法保证识别全部缺口。这里的历史收益不包含完整分红现金流或交易成本模型。

导出CSV的收益率以小数保存，例如`0.05`表示`5%`；缺失指标保持空值。展开**指标定义与数据检查**可查看公式及明细。

**平均日收益为正，区间最终收益仍可能为零或负数。** 例如100→110→100，日变化为+10%与约−9.09%，平均约+0.45%，累计为0%。可视化价格表现不含手续费、滑点及完整分红现金流。

## 6. 自定义策略回测

当前入口名称为“自定义策略回测”。本节先说明双均线执行逻辑；其他策略和条件编辑见下方操作说明，设计记录见[平台基础与交互设计](../06-engineering-records/01-PLATFORM_FOUNDATION.md)。

### 6.1 操作步骤

1. 进入“自定义策略回测”，选择本地证券、缓存复权和日期。
2. 阅读顶部归一化研究模型说明。
3. 配置短期/长期窗口、初始研究资金、手续费和滑点。
4. 确保短期窗口小于长期窗口，点击**运行回测**。
5. 查看策略/基准净值、回撤、信号与成交标记、绩效对比表。
6. 查看**已成交记录**、**全部信号订单（含取消/未成交）**、**逐日现金与持仓**。

| 默认参数 | 数值 |
| --- | --- |
| 短/长期均线 | MA5 / MA20 |
| 初始研究资金 | 100000研究单位 |
| 双向手续费率 | 0.03%，买入和卖出各自按成交额计提 |
| 单边滑点 | 0.05%，买入加价、卖出减价 |
| 无风险年利率 | 0% |
| 年化参数 | 252个交易日 |

默认MA5/20需要至少21个可交易观测才能判断相邻完整均线的交叉，达到长度仍不保证出现交易。新上市或短区间可能数据不足。

### 6.2 新增策略与自定义条件

“选择策略”可选双均线、价格通道突破、RSI阈值、日线研究网格和自定义条件。每项都有展开的通俗说明及独立参数。

- 通道：收盘突破此前N日最高收盘进入，跌破此前M日最低收盘退出，门槛不含当天。
- RSI：简单滚动平均涨跌幅计算RSI；向下穿过低阈值进入，向上穿过高阈值退出，不保证反弹。
- 网格：用首日开盘=100的研究价格设置边界与档数。收盘跨档形成下一开盘目标仓位委托，可以分批调仓；不是日内逐档成交模拟。
- 自定义：条件编辑器或严格JSON；支持研究OHLC、MA、简单RSI、成交量/成交额、成交量均线、较前次收盘变化、持仓收益率和持仓观测日数。允许历史偏移及倍数；条件组可嵌套“且/或”，最多3层组、60节点，每组最多8项。空仓只判断买入，持仓只判断卖出。必须审阅括号预览并确认，规则改变需重新确认。
- 每种预置策略的“这项策略在做什么？”包含数字例子、每项参数含义和调整影响。自定义条件不显示这段通用介绍，直接进入编辑器、示例和字段帮助。短期窗口5就是最近5个交易观测收盘均值，大致一周；5/20只是教学默认值，不是最佳参数。资金/费用参数旁也有帮助。
- AI草案：只在用户点击时调用已配置模型，发送条件描述而非行情。草案需校验、放入编辑器并人工确认；不执行任何生成代码。没有API也可以手工编辑。

新建自定义策略时，买入和卖出条件各默认1条。编辑完成并确认括号预览后，可填写策略名称和说明：

- 不勾选“保存到本地”：只保存在本次Streamlit会话，关闭应用后消失。
- 勾选“保存到本地”：写入 `data/user_strategies/active/`，以后可以直接加载。
- “更新已加载策略”保留原来的保存位置；“另存为新策略”按当前复选框决定保存位置。
- 数据管理的“自定义策略”标签支持批量移入回收区、恢复和经过二次确认的永久删除。

策略文件只保存规则和执行口径，不包含行情、回测结果或API Key。同名策略不会静默覆盖。

没有所选证券缓存时，可展开全市场搜索（代码表可能在首次明确搜索时联网），确认证券后再点击缺失数据弹窗。获取成功不自动开始回测，仍需点击“运行回测”。研究报告中的回测分析目前仍明确使用双均线，不会把它冒充当前自定义策略结果。

### 6.3 载入放量上涨与止盈止损例子

选择自定义条件，点击“载入例子：放量上涨 + 10%止盈止损 / 均线退出”。

买入条件全部满足：今日成交量≥上一交易观测成交量×2，且今日收盘高于前收盘。
卖出条件任一满足：持仓收益率≥10%，或≤−10%，或MA5下穿MA20。

- “上涨”与阳线不同：上涨比较前收盘，阳线比较当天开盘。
- 指标历史偏移0表示今天、1表示前一交易观测；倍数2表示乘2，不支持负偏移或未来数据。
- 收益率常量选择百分比后填10表示10%，填−10表示−10%；引擎保存为0.10/−0.10。
- 添加子条件组可以表达A且（B或C），或（A且B）或（C且D），中文预览会保留括号。
- 持仓收益率=收盘持仓市值/剩余成本−1，成本包含已成交买入手续费及滑点，不预扣卖出费用。不是整个账户累计收益。清仓后重置成本，新交易重新计算；部分卖出按比例移除剩余成本。
- 止盈止损仅在收盘触发，下一开盘执行。忽略费用，成本10、收盘11触发10%止盈，次日开盘10.8则约8%；成本10、收盘9触发止损，次日8.7则可能亏13%。阈值不保证实际成交收益或最大亏损。
- 日线不能可靠推断盘中先止盈还是先止损，本版不进行盘中精确止损。缺失量额/历史会标为不可判断，不能补零；依赖成交量且全段单位未知时提示刷新。

### 6.4 双均线怎样执行

- 短均线由下向上突破长均线形成买入信号；反向形成卖出信号。
- 收盘后形成信号，在**下一条缓存日线开盘**模拟执行，不在信号当天收盘成交。
- 首日空仓，只做多，无借款或卖空；首次完整均线已经在上方，不自动买入。
- 买入按100模拟单位向下取整，资金不足会拒绝订单；卖出一次清空模拟持仓。
- 最后一天信号没有下一条日线，记录为未成交；末日持仓按收盘估值，不强制平仓。
- 无效开盘、零成交等情况可能取消订单。相邻记录按本地交易日日历核对：国庆等已声明休市的长假可以正常衔接；中间存在应开市日却无行情、或日期超出日历覆盖时，跨缺口条件不使用且待执行订单取消。

**这里的资金、价格、持仓和费用是研究单位。** 引擎将样本首日开盘设为100，不是用复权价模拟精确人民币现金流。未完整模拟公司行为、具体板块交易单位、印花税、过户费、涨跌停和真实流动性，不等同于可实盘执行回测。

### 6.5 结果与下载

绩效包括累计/年化收益、年化波动、最大回撤、夏普及成交次数。成交次数按成交委托计，买和卖各算一次，不是完整往返次数。零波动等情况夏普可能为空。基准在首个可交易开盘按相同成本和整手规则买入并持有，因此与可视化页的首收盘基准收益可能不同。

可下载：

- **每日账户 CSV**：逐日现金、持仓、净值等。
- **成交记录 CSV**：实际模拟成交的订单。
- **完整回测 ZIP**：每日账户、全部订单、成交、基准订单、绩效CSV和假设JSON，共6个文件。

表单里的修改需要点击“运行回测”提交。未提交时已有结果仍属于上次参数；证券、区间、已提交参数或缓存变化后需重新运行，页面不会自动回测或下载。

## 7. 研究报告

### 7.1 无API也能使用

1. 首页点击**进入研究报告**。
2. 搜索已缓存证券的代码或中文名称，并从选择器选择。
3. 选择日期、缓存请求复权和报告类型。
4. 未配置模型时保持**本地规则模板（无需API）**。
5. 相关类型可展开“双均线回测参数与研究口径”，确认参数。
6. 点击**生成研究报告**。

本页搜索范围是**已缓存证券**，不是全市场股票列表。找不到时前往股票数据获取；完全没有所选区间数据时不生成。部分覆盖会明确警告，仅分析实际可用范围。

| 报告类型 | 内容 |
| --- | --- |
| 股票历史表现分析 | 历史收益、波动、回撤及数据概况 |
| 技术指标分析 | 末个有效观测的价格、MA5/MA20和相对位置 |
| 双均线策略回测分析 | 根据本页参数运行研究回测，比较策略与买入持有 |
| 综合分析报告 | 合并历史表现、技术指标及有效回测 |

报告统一保留A—E章节：数据概况、历史收益与风险、技术观察、策略回测、限制与风险。未选择的分析节明确写明未包含；数据不足时不编造指标。

### 7.2 模型做什么、核验什么

Python负责计算指标、运行回测、判定适用陈述，模型只选择重点和组织受控句式。平台核对JSON结构、代码、名称、日期、句式和引用原值，再用Python填入显示值；不把无法可靠验证的自由长文标记为已核验。

| 生成方式 | 含义 |
| --- | --- |
| 本地规则报告 | 未调用外部模型，直接使用已验证事实和模板 |
| LLM辅助报告（受控句式编排） | 模型返回的结构和引用通过本地检查 |
| 失败回退规则报告 | 模型调用失败或输出被拒绝，最终显示规则报告及原因 |

核验通过不等于独立认证上游数据真实，也不代表策略有预测能力。

### 7.3 可选模型配置

不配置这一节，也能使用全部本地规则功能。最简单的配置方式是进入**首页→数据管理→模型与 API**：

1. 选择“智谱 GLM-4.7-Flash”“智谱 GLM-5.3-Flash”预设，或“自定义 OpenAI 兼容 API”。
2. 智谱预设只需填写自己的模型标准API Key；自定义配置还需填写名称、模型和API基础地址。
3. 点击“保存到本次会话”不会联网；只有点击“测试连接（调用1次）”才会发出一次最小JSON请求。
4. 默认不把Key写入项目文件；结束会话后需重新填写。不要把Key截图、分享或提交Git。
5. 如需长期使用，可点击“另存为本地配置”，并选择是否把Key安全保存到操作系统钥匙串。普通配置JSON只包含名称、模型和地址。
6. “已保存配置”支持加载和批量移入回收区。移除配置时钥匙串中的Key立即删除；回收区只保留非敏感配置，恢复后必须重新输入Key。

需要长期使用时，也可在本机复制`.streamlit/secrets.toml.example`为`.streamlit/secrets.toml`，按服务商实际信息填入：

```toml
RESEARCH_LLM_BASE_URL = ""
RESEARCH_LLM_MODEL = ""
RESEARCH_LLM_API_KEY = ""
```

基础地址不要包含末尾`/chat/completions`，模型需支持当前Chat Completions兼容协议及JSON请求格式；远端地址要求HTTPS。也可配置同名环境变量，环境变量优先。不要把真实密钥写入代码、示例文件或Git；修改后重启应用。

环境变量/Secrets、当前会话配置和钥匙串中凭据完整的本地配置可以同时被识别，相同模型与地址会去重。页面仅列出完整配置模型，显示“已配置，调用时验证”；不会在进入页面时提前调用API。实际可用性、费用和服务条款以你所用服务为准。点击生成会向该服务发送结构化统计JSON，使用前应确认允许发送这些研究数据。

用户已在本机报告自定义 `glm-5.3-flash` 连接测试成功；自动化测试仍使用Mock，不读取或调用用户的真实API Key。线上可用性仍取决于账户资源包、限额和服务状态。

### 7.4 重新生成和保存

- 相同参数和相同缓存再次点击**生成研究报告**复用已有结果，避免重复调用。
- **重新生成**会再次执行当前配置，选择外部模型时会再次调用API。
- 改变证券、日期、复权、类型、相关参数、模型或缓存后，旧报告隐藏，需重新生成。
- 点击**下载Markdown**保存完整报告，点击**下载分析指标CSV**保存原始指标及来源。
- 展开**核验依据与结构化数据**查看事实和引用。

报告主要保存在当前会话中，想长期保留应主动下载。

## 8. 数据状态与来源

### 8.1 股票/ETF行情

| 状态 | 正确理解 |
| --- | --- |
| LIVE_FETCHED | 本次已请求并保存日线，不表示实时逐笔行情 |
| CACHE | 已记录查询覆盖所选区间；不代表今天刚刷新或上游未修订 |

### 9.2 缓存与备份

- 永久缓存关闭后保留；会话临时缓存按失效与过期规则清理，应用停止期间由下次运行兜底。两者均不提交Git。
- 行情CSV和相应JSON元数据应成对备份，尽量不要手动改列名、代码或复权标记。
- 研究结果可通过下载保存；修改缓存后旧结果可能不再适用，应重新生成。
- 数据管理支持多选缓存后批量移入回收区，以及多选回收条目恢复。列表展示证券代码、名称、类别、复权、实际日期范围和记录数，不再要求用户识别内部目录编号。同一证券/复权的多个回收版本不能在同一批次恢复，以免系统替用户选择版本。
- 移入回收区是移出可用缓存，不会立即释放回收区空间。本次临时行情可单条转存永久；已有永久条目时拒绝覆盖，先处理旧条目。
- “结束本次使用并清理临时数据”立即清理本会话目录并使旧研究结果失效，不清理永久缓存或浏览器下载。
- 当前没有回收区永久清空按钮，若确需释放其空间，可核对备份后在文件管理器处理对应目录。

### 12.1 主要代码职责

| 模块 | 职责 |
| --- | --- |
| `app.py`、`src/home_page.py`、`src/navigation.py` | 精简入口、首页与页面导航 |
