# 交易日、模型配置与缓存管理优化记录

记录日期：2026-10-22。

## 目标与结果

- 成交量/成交额异常改为逐日分类，明确“已有价格日线但成交字段待核验”，不再把它描述成交易日缺失。159516旧回收缓存中可复核到的6个早期异常日期属于`CONFLICT`来源冲突，并非国庆休市记录。
- 回测连续性改用项目内provider-derived交易日历。已声明休市的长假允许衔接；中间跳过已声明开市日时取消待执行订单；日历未覆盖时标为未核验。
- 选择自定义条件策略时不显示“这项策略在做什么？”通用说明，保留编辑器、例子、字段帮助、中文条件预览和人工确认。
- 数据管理“模型与 API”现含智谱`glm-4.7-flash`、`glm-5.3-flash`预设和自定义OpenAI兼容连接。Key默认仅保存在当前Streamlit会话；用户可选择把普通模型配置保存为本地JSON，并把Key单独交给操作系统钥匙串。保存不联网，测试连接明确调用一次。
- 本地行情和回收区支持多选、批量移入与批量恢复。回收区展示证券代码、名称、市场、类别、复权、实际日期、记录数和归档时间，不再用内部UUID作为用户标签。同一目标的多个版本不能同批恢复。
- 所有可见“AI研究报告”改为“研究报告”；内部路由`ai_report`保留。首页两个进阶卡片使用相同说明区域高度，小屏恢复自然高度。

## 安全与数据边界

- 自动化测试没有读取或调用用户的真实API Key，模型请求使用Mock。
- API Key不写入代码、模型JSON、回收区、日志、导出或Git；删除本地模型配置时立即删除钥匙串凭据，恢复后需要重新输入。会话或本地配置保存都不会验证联网，只有独立测试/生成按钮调用。
- 休市日不补零、不生成虚假行情；交易日日历超出覆盖时不猜测。
- 批量移除仍进入可恢复目录；恢复不覆盖已有永久缓存，回收副本保留。
