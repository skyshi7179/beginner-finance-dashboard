# 自定义策略与模型配置本地管理

更新日期：2026-10-22。

## 数据流

自定义策略编辑器先在会话状态中形成并校验规则。用户确认后，可以只保存到本次会话，也可以写入 `data/user_strategies/active/`。本地策略使用带版本号的独立JSON；数据管理只移动经过校验的文件，并提供回收和恢复。

模型配置分为两部分：

- 名称、模型代码、服务商和API基础地址写入 `data/model_profiles/active/`。
- API Key在用户明确勾选后交给操作系统钥匙串，项目JSON只记录“是否曾安全保存”，不保存密钥内容。

加载模型时，程序合并环境变量、Streamlit Secrets、当前会话配置及具有可读钥匙串凭据的本地配置，并按模型和基础地址去重。进入页面、切换选项和保存配置都不会联网。

## 删除与恢复

- 策略移入回收区后保留完整规则，可以恢复。
- 模型配置移入回收区时立即删除系统钥匙串中的Key。
- 模型回收区只保存名称、模型代码和地址；恢复后必须重新输入Key。
- 永久删除位于回收区的高级区域，需要再次确认。

## API错误与重试

连接测试始终只调用一次。错误显示HTTP状态与经过限制长度、密钥脱敏的业务码说明。研究报告和AI策略草案只有在智谱明确返回业务码1305（模型过载）时，才按2秒、5秒进行最多两次有限重试；其他错误立即停止。

## 验证边界

自动化测试使用临时目录、Mock模型和Mock钥匙串，不读取用户真实Key，也不向真实模型发起请求。macOS虚拟环境已识别 `keyring.backends.macOS.Keyring` 后端；首次由应用写入钥匙串时，系统仍可能根据本机安全策略弹出授权提示。
